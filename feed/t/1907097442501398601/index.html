ORMs are good even if you’re a SQL god:

Use ORMs for your side projects because the performance impact is approximately zero and the convenience is 100x.

Use ORMs for work projects so next quarter you can rewrite it in raw SQL, reduce COGS by several million, and get promoted.

I still remember the day @rails came into my life.

I loved modeling entity relationships, set theory, writing SQL and bridging objects/tables "by hand".

Then ActiveRecord beautifully put it all together, made it human-readable, and it felt (and still does) just so right ❤️
