In the past week, I've had lunch with, respectively, 5 friends of mine. All of them top-notch non-technical founder-types with solid track-records.

Each conversation quickly circled in on AI claws and how they're experimenting with it, including the development and operations part. I LOVE that they're finally enabled to do this on their own and I love seeing that creative/hacker-y spark in their eyes. It feels like they've waited ages for a technical sparring-partner that could deliver at the thought-of-speed.

I am so happy for them and some of their self-made products are impressive. Technically and product-wise.

What I also noticed, and that's a surprise for me, is that when they go into very deep detail on their firewall configuration, I feel sad because I feel they've been kinda nerd-sniped/FOMO'd into this rabbit-hole and I am not sure how and when they'll find their way out again.

PS: Hand-written by Alexis, delivered to Twitter by Alexis' nanoclaw assistant

[continued thought]

So, this is NOT about me wanting to gatekeep vibe-coding and vibe-shipping. I absolutely welcome it. In fact, they leveled up so quickly that our technical conversations as real as they get.

But they also look like they haven't slept in days, they're pale. They seem more neurotic than usual. They're a bit less charismatic and a bit more lost. And I guess that makes me feel as if I'm "losing the good ones" to the infinite techno/AI rabbit-hole that I learned to maange and navigate a long time ago.

Anyways. Mixed emotions. More to come!

Alright - just keeping a tab on getting a nanoclaw assistant to a point where I feel like it's okay to stop fiddling with the setup:

Yesterday, I had precisely 125€ in Anthropic API credits. The basic nanoclaw /setup and /customize yesterday came in at around ~15€.

Then, running /setup-telegram, testing out agent swarms and building a simple status-dashboard that I can access from my laptop added another 20€.

So, I've spent ~35€ so far and still feel like I'm getting fantastic value.

And, what I LOVE about nanoclaw is the clear separation between using Claude Code for setting things up, customizing them, running ops etc. vs. using the Anthropic API for running the actual assistant(s).

Currently, I'm using Anthropic's Agent API for both, Claude Code and the assistants.

Given how I'm using Claude Code to build/setup/ops the system, I feel it would be fair use to use my Pro subscription here instead of paying directly for API tokens.

And given how the Pro subscription (as someone on HN wrote a few days ago) is, after all, like a ticket for one person to an all-you-can-eat buffet, I feel it would not be cool to use my Pro subscription here and it's totally right to pay for API tokens.

So, these are some of my thoughts here from today.

Next up: Since agents are run in ephemeral containers (yay!), I'm currently having Claude Code build me a separate docker container that runs a persistent desktop environment (KDE FTW) that will include a Chrome browser that both, I (via SSH/VNC) and the agent (via CDP) will have access to and can use.

Aaaaand 10€ worth of Anthropic API tokens later, here we are!
