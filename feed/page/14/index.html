LOL, got 100% nerd-sniped by my friend Sönke this week and wound up building a small spaceship.

On Monday he's like "Hey, what if you found obscure seed phrases embedded in public texts? You'd only need to remember the name of the book and the paragraph and go from there."

I honestly could care less about crypto(currencies) and I'm 100% sure this is like cryptanalysis 101. But, yeah, it seemed like an interesting problem anyways.

First, I downloaded a few hundred books from Gutenberg, wrote a ruby script and found BIP39 word sequences with a tolerable buffer for filler-words.

Then, I was like, okay, gotta now check them against actual addresses. Downloaded a list of funded ETH addresses. Wrote the checker in ruby. Ran it. No hits but this was now definitely weirdly interesting.

Because: And what if I downloaded the whole pg19 text corpus to scan! And what if I'd add BTC addresses! And what if I checked every permutation of the seed phrase!

Everything got really slow once I got to processing 12G of raw text for finding sequences and then checking a few million candidates with 44.000+ variations per candidate.

So, let's rewrite this into C! And since I've got 16 cores, let's parallelize this puppy! And since it's a MacBook, let's use GCD! Optimize all the things!

Lol, so NOW this thing is so fucking FAST. Takes four minutes to go through the full pg19 corpus and generates 64,205,390 "interesting" seed phrases. The fully parallelized checker (see Terminal screenshot) processes 460 derived addresses per second.

I really don't care if I get a match or not. I feel like I started with building a canoo and wound up with a spaceship is in itself just the best thing in the world.

Anyways. Just wanted to share this. If anyone wants, I can put the whole thing on github, too. Let me know!

bipscan

2 stars · Ruby

BIP-39 Seed Phrase Finder

Find BIP-39 seed phrase sequences hidden in classic literature and generate seeds from common patterns.

Quick Start

1. Bootstrap Data

Download the essential data files (BIP-39 wordlist, address lists):

./src/scripts/download_data.sh

2. Download Text Corpora

# Curated texts (~150 classic books)
./src/scripts/download_texts.sh

# Or full PG19 corpus (~28K books, ~12GB)
./src/scripts/download_pg19.sh

3. Build C Workers

cd src/c && make btc manager paragraph

Generate Seeds

Paragraph-Based Seeds (from texts)

Extract BIP-39 words from paragraph starting points in literature:

# Generate 24-word seeds from curated texts (default)
ruby src/ruby/generators/generate_paragraph_seeds.rb texts

# Generate 12-word seeds
ruby src/ruby/generators/generate_paragraph_seeds.rb texts --words=12

# From PG19 corpus (split into 10 batches of ~2800 books each)
ruby src/ruby/generators/generate_paragraph_seeds.rb pg19/batch_01 --words=24
ruby src/ruby/generators/generate_paragraph_seeds.rb pg19/batch_02 --words=12
# ... through batch_10

Birthday-Based Seeds

Generate seeds using birthday date components as word indices:

# 24-word seeds (default)
ruby src/ruby/generators/generate_birthday_seeds.rb

# 12-word seeds
ruby src/ruby/generators/generate_birthday_seeds.rb --words=12

Generates seeds for years 1960-2000 using:

  • Multiple date formats (US, EU, ISO)
  • Full year and short year variants
  • Absolute indexing and walk-through modes

Birthday Hash Seeds

SHA256(date_string) derivation for all date formats:

ruby src/ruby/generators/generate_birthday_hash_seeds.rb --words=12
ruby src/ruby/generators/generate_birthday_hash_seeds.rb --words=24

Password-Based Seeds

Generate seeds from common passwords using SHA256 derivation:

ruby src/ruby/generators/generate_password_seeds.rb --words=12
ruby src/ruby/generators/generate_password_seeds.rb --words=24

Rockyou Wordlist Seeds

Generate seeds from the full rockyou.txt password list:

# First download rockyou.txt to data/wordlists/
ruby src/ruby/generators/generate_rockyou_seeds.rb --words=24

Character Sequence Seeds

Generate seeds using mathematical and linguistic patterns:

ruby src/ruby/generators/generate_character_sequences.rb

Methods include:

  • Character-based (a-z groupings, reverse order, alternating)
  • Mathematical (Fibonacci, primes, golden ratio, triangular numbers)
  • Pattern-based (word length, skip patterns, phonetic)
  • Cultural (keyboard layouts, musical scales, chess notation)

Check Seed Phrases

Use the C-based parallel manager with live TUI:

./src/c/check_seeds_manager output/seeds/my_seeds.txt [workers]

Example UI:

Features:

  • Splits work across all CPU cores (configurable)
  • Live progress display for each worker
  • Shows derivation and checking phases
  • Resume support: Progress is saved automatically
  • Skip duplicates: Already-processed seeds are automatically skipped
  • Graceful Ctrl+C handling with progress persistence

Etherscan API Check

Check actual on-chain balances:

ruby src/ruby/generators/check_seeds_etherscan.rb output/seeds/my_seeds.txt YOUR_ETHERSCAN_API_KEY

Get an API key: https://etherscan.io/apis (free tier: 100K requests/day)

Output Files

All generators support --words=12 or --words=24 and include a marker in the filename:

  • texts-paragraph-12w-seeds-YYYYMMDD-HHMMSS.txt (12-word)
  • texts-paragraph-24w-seeds-YYYYMMDD-HHMMSS.txt (24-word)
  • birthday-absolute-full-year-us-12w-YYYYMMDD-HHMMSS.txt
  • etc.

Derivation Paths Covered

The seed checkers derive addresses from 14 different wallet formats:

NamePathDescription
BIP-44 Standardm/44'/60'/0'/0/{i}MetaMask, Trezor, most wallets
BIP-44 Accountsm/44'/60'/{a}'/0/{i}Multiple accounts (MetaMask)
Ledger Livem/44'/60'/{a}'/0/0Ledger Live (one addr per account)
Ledger Legacym/44'/60'/0'/{i}Ledger legacy, old MEW/Jaxx
BTC Legacym/44'/0'/0'/0/{i}Bitcoin P2PKH (1…)
BTC SegWitm/49'/0'/0'/0/{i}Bitcoin P2SH-SegWit (3…)
BTC Native SegWitm/84'/0'/0'/0/{i}Bitcoin Bech32 (bc1q…)

Where {a} = account index (0-19) and {i} = address index (0-499).

Total addresses derived per seed: ~53,000

Because: And what if I downloaded the whole pg19 text corpus to scan! And what if I'd add BTC addresses! And what if I checked every permutation of the seed phrase!

Everything got really slow once I got to processing 12G of raw text for finding sequences and then checking a few million candidates with 44.000+ variations per candidate.

So, let's rewrite this into C! And since I've got 16 cores, let's parallelize this puppy! And since it's a MacBook, let's use GCD! Optimize all the things!

Lol, so NOW this thing is so fucking FAST. Takes four minutes to go through the full pg19 corpus and generates 64,205,390 "interesting" seed phrases. The fully parallelized checker (see Terminal screenshot) processes 460 derived addresses per second.

I really don't care if I get a match or not. I feel like I started with building a canoo and wound up with a spaceship is in itself just the best thing in the world.

Anyways. Just wanted to share this. If anyone wants, I can put the whole thing on github, too. Let me know!

I would say it's pretty performance but, the actual cryptanalysis is very naïve. I call it a cute-force attack 😁
