Autonomous Research with AI: "We don't write the rules. We just discover them." — how an agent searches for the groundrule, and what makes the loop different

Autoresearch on a job-shop scheduling problem dressed up as a lunch rush: one grill, one shared range, sequencing as the only lever, and an AI agent that proposes candidate rules, runs them across simulated services, and keeps whatever beats the champion — trained on six scenarios, then held out against three more to check it found a principle, not a memory. Built on Nima H. Siboni’s “The Heuristic Scientist: Open-Ended Algorithm Discovery with LLMs” workshop.
