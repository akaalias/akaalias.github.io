Bookmarked from Nick Dobos @NickADobos

Super cool generative Ui ai demo from vercel.

Some thoughts on chat as an interface & dynamic UI:

-chat makes sense as standalone app, like chatGPT. Or as a chatGPT wrapper with extra bells and whistles

-but for existing apps, the strategy everyone seems to be going for is “add a chat interface” inside your app.

But scrolling timelines of chat make no sense in 90% of cases

Instead a better option for this same goal is something like a cmd+k cursor. sh style, or superhuman-sque pull to refresh style to issue commands. No long history chats, instead: single commands translated & issued by a GPT wizard, that can trigger into any function in your app

Imagine:
“How can I edit this video to add sparkles?”
“You can click this… then… then…”
Vs
“How can I edit this video to add sparkles?”
“Here’s your video, I applied x y z buttons”

Generative chat Ui like this demo below is gonna be huge, but it will be much much better outside of pure chat back and forth scrollable timelines. Better to be inline another full fledged app/website
